Bosh sahifa static relative absolute fixed sticky

CSS position

Besh xil position qiymati, har biri uchun alohida sahifa. Tepadagi tugma bilan dark mode'ni yoqib ko'ring.

Sahifalar

static

Standart holat. Oqim bo'yicha.

Ochish

relative

O'z joyiga nisbatan suriladi.

Ochish

absolute

Eng yaqin "ota"ga nisbatan.

Ochish

fixed

Brauzer oynasiga mahkamlanadi.

Ochish

sticky

Aylantirganda yopishib qoladi.

Ochish

Qisqacha taqqoslash

positionOqimda joy egallaydimiNimaga nisbatan
staticHaNisbat yo'q, oddiy oqim
relativeHa, eski joyi qoladiO'zining oddiy joyiga
absoluteYo'qEng yaqin positioned ota-elementga
fixedYo'qBrauzer oynasiga
stickyHaAylantiriladigan konteynerga

Tugmalar: ::before va ::after

Ustiga olib boring: ::before fonni yuguritadi, ::after orqadagi ramkani siljitadi.

Outline tugma Solid tugma 

.btn {
  position: relative;
  isolation: isolate;
}
.btn::before {            /* hover'da yuguruvchi fon */
  content: "";
  position: absolute;
  inset: 0;
  z-index: -1;
  background: var(--accent);
  transform: scaleX(0);
  transform-origin: left;
}
.btn::after {             /* orqadagi ramka */
  content: "";
  position: absolute;
  inset: -2px;
  z-index: -1;
  border: 2px solid var(--highlight);
  transform: translate(5px, 5px);
}
.btn:hover::before { transform: scaleX(1); }
